# Benchmark Results — 2026-03-10

## Setup

- **Dataset**: [big.txt](https://norvig.com/big.txt) (6.2 MB, 6,488,666 chars)
- **Tokenizer**: GPT-2 (`gpt2/tokenizer.json` from HuggingFace)
- **Runs**: 3 per variant (mean ± stdev)
- **CPU**: Intel Xeon E5-2670 v3 @ 2.30GHz (x86_64)
- **Compilers**: rustc 1.90.0, g++ 13.3.0
- **C++ standard**: C++23
- **All binaries stripped**, dynamically linking only libc/libstdc++/libm. Note: even the rust binary also links to libc++, so its a fair game.

## How to Reproduce

```bash
make bench
```

This will:
1. Download benchmark data (big.txt + GPT-2 tokenizer.json)
2. Clone the reference [thammegowda/tokenizers](https://github.com/thammegowda/tokenizers) repo (`tg/cpp` branch that has cpp bindings for comprison)
3. Build Rust, C++ bindings, and tokenizerpp benchmark binaries
4. Run 3 iterations of each and print comparison
